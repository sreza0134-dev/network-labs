# Network Labs

Hands-on network labs that I built to practice the skills from my CCNA. Most use Cisco Packet Tracer, a free network simulator. One uses Wireshark on my own home network.

## Labs

| Lab | What it covers | Tool | Status |
|---|---|---|---|
| 1. Office network | VLANs, routing between VLANs, DHCP, access list, NAT, DNS | Packet Tracer | Done |
| 2. Fix the broken network | Finding and fixing five network faults | Packet Tracer | Planned |
| 3. See the traffic | Looking at real DHCP, DNS, ARP, ping, and TCP packets | Wireshark | Planned |
| 4. Two offices joined by a **VPN** | Routing between two sites, then an encrypted **VPN** tunnel (IPsec) | Packet Tracer | Planned |
| 5. Switch security | Port security, SSH, and turning off unused ports | Packet Tracer | Planned |
